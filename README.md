# DecodeLabs Project 2 - Responsive Web Layout

## 📖 About
Complete implementation of DecodeLabs Project 2 for Industrial Training Kit (Batch 2026). Demonstrates responsive web design principles with CSS Media Queries, Flexbox, Grid, and modern web technologies.

## ✅ Requirements Met
- CSS Media Queries (mobile-first)
- Responsive Navigation (Popover API)
- Fluid Typography with clamp()
- Flexbox & Grid Harmony
- Proper Spacing & Alignment

## 🚀 Live Demo
[View Project]([index.html](https://chaithanya8861.github.io/decodelabs_task2/))

## 📱 Features
- **Responsive Navigation**: Hamburger menu → Inline desktop
- **Fluid Typography**: clamp(1rem, 2.5vw, 2rem)
- **Layout**: CSS Grid + Flexbox
- **Mobile-First**: Progressive enhancement
- **Smooth Scrolling**: Navigation links

## 🛠️ Technologies
- HTML5 (Popover API)
- CSS3 (Flexbox, Grid, Media Queries)
- JavaScript (Popover control)
- Google Fonts (Inter)

## 📱 Responsive Breakpoints

| Breakpoint | Layout |
|------------|--------|
| < 640px | Single column, hamburger menu |
| 640-1023px | Two columns, hamburger menu |
| ≥ 1024px | Three columns, inline navigation |

## 🚀 Quick Start
1. Open `index.html` in browser
2. Resize window to test responsiveness
3. Click hamburger menu (mobile) or nav links (desktop)
